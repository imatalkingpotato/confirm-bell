# 컨펌벨

픽셀 사무실에서 뿅망치로 컨펌을 재촉하는 브라우저 게임.

- 캐릭터별 대사, 10콤보 크리티컬·50콤보 대형 타격, 1,000~5,000콤보 특별 연출
- 사용자 제공 아바타를 캔버스 픽셀 도형으로 구현 (이슬 실루엣 / 지영 J)
- YouTube 공식 임베드 BGM. 자동 재생이 차단되면 첫 타격 또는 재생 버튼으로 시작
- 기존 `confirmbell_v3` 개인 기록과 Firebase 팀 리더보드 유지

## 로컬 확인

```sh
python3 -m http.server 8769 --bind 127.0.0.1
```

`http://127.0.0.1:8769/?preview=1`을 연다. **테스트 시 `preview=1`을 반드시 사용**한다. 이 모드는 Firebase 요청과 개인 기록 저장을 모두 끄며 새로고침하면 초기화된다.

## 테스트

```sh
node --test tests/game.test.cjs
```

5,000회 타격, 콤보별 연출, 캐릭터별 대사, 입력 중복 방지, 기존 저장값 유지, 모션 축소, 음악 상태 전환을 검사한다. 실제 화면·오디오·YouTube 임베드는 브라우저에서 별도로 확인한다.

## 구성

- `index.html`: 게임 화면
- `styles.css`: PC·모바일 레이아웃
- `game.js`: 픽셀 렌더링, 게임, 효과음, 기록
- `music.js`: YouTube 음악 제어

공통 추가 대사는 사용자 선택 후 반영하며, 일일 첫 방문 인트로는 후속 작업이다.
