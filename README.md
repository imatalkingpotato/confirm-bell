# 컨펌벨

픽셀 사무실에서 망치로 컨펌을 재촉하는 브라우저 게임.

- 캐릭터별 대사, 10콤보 크리티컬·50콤보 대형 타격, 1,000~10,000콤보 특별 연출
- 사용자 제공 아바타를 캔버스 픽셀 도형으로 구현 (이슬 실루엣 / 지영 J)
- YouTube 공식 임베드 BGM. 자동 재생이 차단되면 첫 타격 또는 재생 버튼으로 시작
- 기존 `confirmbell_v3` 개인 기록과 Firebase 팀 리더보드 유지

## 로컬 확인

```sh
python3 -m http.server 8769 --bind 127.0.0.1
```

`http://127.0.0.1:8769/?preview=1`을 연다. **테스트 시 `preview=1`을 반드시 사용**한다. 이 모드는 Firebase 요청과 개인 기록 저장을 모두 끄며 새로고침하면 초기화된다.

## 테스트

```sh
node --test tests/*.test.cjs
```

10,000회 타격, 콤보별 연출, 캐릭터별 대사, 입력 중복 방지, 기존 저장값 유지, 모션 축소, 음악 상태 전환을 검사한다. 실제 화면·오디오·YouTube 임베드는 브라우저에서 별도로 확인한다.

## 구성

- `index.html`: 게임 화면
- `styles.css`: PC·모바일 레이아웃
- `game.js`: 픽셀 렌더링, 게임, 효과음, 기록
- `music.js`: YouTube 음악 제어

공통 추가 대사는 사용자가 선택한 8개만 반영한다. 개인별 대사와 번갈아 표시한다.

## 인트로 및 음악

- 한국 시간 기준 하루 첫 방문에 콜라주 인트로를 표시한다. `intro=1`은 강제 다시 보기, 화면의 다시 보기 버튼도 지원한다.
- 월별 덱 12장과 **픽셀 자체가 흐려진** 현황판 1장만 배포한다. 개인정보가 있는 원본 현황판은 저장소에 포함하지 않는다.
- 세 문장 순차 페이드인 → 화이트아웃. Escape/건너뛰기 및 모션 축소를 지원한다.
- 인트로 재생 중 게임 입력은 잠기고, 종료하면 이전 화면과 포커스로 돌아온다.
- 음악 패널은 YouTube IFrame 재생 상태/시간을 사용한다. 탐색 바는 `seekTo`로 실제 위치를 변경한다. 파형은 재생 상태에 맞춘 장식 애니메이션이며 실제 주파수 분석은 아니다.
- 브라우저의 자동 재생 제한 시 첫 클릭 또는 재생 버튼이 필요할 수 있다.

## 누적 타격 흔적

기존 개인 기록은 최초 한 번 현재 판 진행으로 이관한다. 이후 캐릭터별 현재 판 타격을 별도로 저장하며 1,000타마다 눈가 멍 → 어깨 붕대 → 머리 붕대 → 볼 밴드 → 팔 깁스·슬링 → 목발 → 다리 깁스 → 수액 → 휠체어 → 병원 침대로 변화한다.

분노 게이지는 캐릭터별 현재 판 10,000타에서 100%가 된다. 10,001번째 타격은 엔딩 문구와 이미지를 페이드 인한 뒤 블랙아웃하고 새 판을 시작한다. 네 캐릭터 진행, 현재·최대 콤보, 개인 타격 카운터를 초기화하며 월 누적과 모든 리더보드 기록은 보존한다. 타격 등급·흔적 숫자·기존 대형 재촉 배너는 표시하지 않는다. 망치는 나무 손잡이와 은색 쇠머리·갈고리를 갖춘 형태로 깊이와 회전을 투영한다.

시각 검수용 `?preview=1&hits=5000`은 각 캐릭터를 5,000타 상태로 시작한다. 실제 기록에는 저장되지 않는다.

- `intro.js`: 일일 인트로, 콜라주, 포커스 복구
- `assets/intro/`: 사용자 제공 월별 덱 / 개인정보를 흐린 현황판
- `gallery.js`: `?preview=1&gallery=1`에서 실제 렌더러로 그린 전체 단계와 타격 순간을 비교한다. 캐릭터 선택을 지원하며 음악이나 실제 기록 저장은 실행하지 않는다.
